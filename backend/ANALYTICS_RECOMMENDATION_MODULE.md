# Transparent Analytics & Recommendation Agent

The **Analytics & Recommendation Agent** is a core multimodal synthesis module of the **Multimodal Attendance & Engagement Agent**. It integrates real-time signals from the **Attendance**, **Session**, **Vision (OpenCV)**, and **Audio Intelligence** modules to produce deterministic, pedagogically grounded teaching suggestions without relying on external LLM APIs or paid cloud infrastructure.

---

## 1. Philosophical & Epistemological Standard

### 1.1 Non-Inference of Internal Psychological States
A foundational ethical and epistemological principle of this system is that **internal cognitive and affective states cannot be directly observed through computer vision or acoustic sensors**:
- **Attention**: Cannot be directly measured. Gaze direction or body orientation is merely physical orientation, not cognitive focus.
- **Emotion & Affect**: Facial landmarks or acoustic pitch do not reliably equal psychological emotions (e.g., interest, boredom, frustration).
- **Understanding & Learning Outcomes**: Comprehension is an internal intellectual attainment evaluated through formative assessment and dialogue, not ambient sensor readings.

> **Epistemological Integrity Declaration**  
> *"Attention, emotional valence, comprehension, and learning outcomes are internal cognitive/psychological states and are NEVER presented as directly measured facts. All system outputs are strictly partitioned into physical sensor observations, statistical estimators, and heuristic pedagogical recommendations."*

### 1.2 Tripartite Taxonomy of Outputs
Every output generated by the engine is tagged with an immutable `item_type`:

| Category (`item_type`) | Definition | Examples |
|---|---|---|
| `OBSERVED_MEASUREMENT` | Direct physical or roster records verified by sensors or authorized instructors. | Confirmed present count (e.g., 6/8 students), session elapsed duration (e.g., 42 min), camera frame timestamps. |
| `STATISTICAL_ESTIMATE` | Mathematical or statistical approximations derived from raw acoustic/spatial signals. | Voice Participation Index (e.g., 28.5%), silence intervals (e.g., 45s), dialogue turnover count (e.g., 14 turns). |
| `PEDAGOGICAL_RECOMMENDATION` | Heuristic instructional advice designed to assist the teacher in pacing and facilitation. | Adding a structured Q&A prompt, pausing for reflection, reviewing attendance anomalies. |

## 2. Rule-Based Reasoning Engine Architecture

The engine runs entirely offline within Python (`backend/services/rule_reasoning_engine.py`) using deterministic rule heuristics.

```
+-----------------------------------------------------------------------------------+
|                            MULTIMODAL DATA INGESTION                              |
+-------------------+--------------------+--------------------+---------------------+
|  Session Module   | Attendance Module  |   Vision Module    |    Audio Module     |
| (Duration, Course)| (Rosters, History) |  (Headcount, Peak) | (Energy, VAD, Turns)|
+---------+---------+---------+----------+---------+----------+----------+----------+
          |                   |                    |                     |
          +-------------------+--------------------+---------------------+
                              |
                              v
         +-----------------------------------------+
         |     RuleBasedReasoningEngine (Offline)  |
         |  - Missing Modality Health Check        |
         |  - Multi-Session Attendance Profiler    |
         |  - Acoustic Discourse State Evaluator   |
         |  - Spatial-Roster Consistency Verifier  |
         +--------------------+--------------------+
                              |
            +-----------------+-----------------+
            |                                   |
            v                                   v
+-----------------------+           +-----------------------+
|   SessionSummary      |           | SessionRecommendation |
| - Verified present    |           | - Category / Severity |
| - Avg attendance rate |           | - Triggered Rule ID   |
| - Speech/silence ratio|           | - Supporting Signals  |
| - Modality flags      |           | - Confidence Limits   |
+-----------+-----------+           +-----------+-----------+
            |                                   |
            +-----------------+-----------------+
                              |
                              v
             [ SQLite Persistent Storage ]
             - table: session_summaries
             - table: session_recommendations
```

### 2.1 The 8 Codified Reasoning Rules

| Rule ID | Name | Trigger Condition | Primary Supporting Signals | Suggested Pedagogical Action |
|---|---|---|---|---|
| `RULE_LOW_PARTICIPATION_QA` | Low Participation Q&A Intervention | `speech_ratio < 0.20` and `session_duration >= 15 min` and `dialogue_turns < 4` | Low vocal density (<20%), low turn-taking (<4 turns) | Introduce an active Think-Pair-Share or targeted Q&A prompt to stimulate student dialogue. |
| `RULE_PROLONGED_MONOLOGUE_PAUSE` | Pacing Reflection Pause | `speech_ratio > 0.70` and `dialogue_turns < 3` and `session_duration >= 10 min` | High vocal density (>70%), unilateral speech stream | Insert a 90-second reflection pause or quick polling check to allow concept consolidation. |
| `RULE_EXTENDED_SILENCE_PROBE` | Extended Silence Check | `longest_silence_s >= 40s` or `silence_percentage > 45%` | Sustained silence interval (>=40s) | Check if students are working through independent tasks, or clarify current exercise instructions. |
| `RULE_ATTENDANCE_DROP_REVIEW` | Cross-Session Attendance Drop | Current attendance rate is >= 15% lower than the 5-session course average | Verified present headcount vs. course historical baseline | Review prior session topics, investigate scheduling friction, or follow up with absent learners. |
| `RULE_HEADCOUNT_DISCREPANCY` | Headcount Discrepancy Reconciliation | Vision peak person detection differs from verified roster by > 1 person | Optical detection peak vs. verified attendance roster | Reconcile physical room occupants with attendance records to verify untracked visitors or late arrivals. |
| `RULE_NOISY_COLLABORATION_WRAPUP` | Collaborative Discourse Wrap-up | High dialogue turnover (> 15 turns) and high vocal density (> 55%) | Elevated dialogue turns and distributed speech activity | Signal transition from peer group discussion back to whole-group synthesis and takeaway sharing. |
| `RULE_BALANCED_DISCOURSE_AFFIRMATION` | Balanced Discourse Affirmation | `0.25 <= speech_ratio <= 0.60` and `dialogue_turns >= 5` | Moderated speech ratio (25-60%), frequent turn exchanges | Affirm instructional pacing; maintain current interactive rhythm. |
| `RULE_MISSING_MODALITY_NOTICE` | Missing Sensor Modality Notice | Audio module disabled or vision detection data missing | Hardware/module configuration state | Explicitly alerts instructor that specific multimodal recommendations are bounded or unavailable. |

## 3. SQLite Persistence & Data Models

### 3.1 `session_summaries`
Persists the aggregated multimodal metrics for a specific class session:
- `id` (INTEGER, Primary Key)
- `session_id` (INTEGER, Foreign Key to `class_sessions.id`, Unique)
- `session_duration_minutes` (FLOAT)
- `verified_present_count` (INTEGER)
- `total_enrolled_count` (INTEGER)
- `attendance_rate` (FLOAT)
- `historical_course_avg_attendance` (FLOAT)
- `attendance_drop_flag` (BOOLEAN)
- `speech_ratio` (FLOAT)
- `silence_ratio` (FLOAT)
- `longest_silence_seconds` (FLOAT)
- `dialogue_turn_count` (INTEGER)
- `vision_headcount_peak` (INTEGER)
- `vision_roster_discrepancy` (INTEGER)
- `audio_modality_active` (BOOLEAN)
- `vision_modality_active` (BOOLEAN)
- `created_at` / `updated_at` (DATETIME)

### 3.2 `session_recommendations`
Stores discrete recommendations and factual observations evaluated by the engine:
- `id` (INTEGER, Primary Key)
- `session_id` (INTEGER, Foreign Key to `class_sessions.id`)
- `rule_id` (VARCHAR(64))
- `title` (VARCHAR(255))
- `category` (VARCHAR(64): `ATTENDANCE_PATTERN`, `SPEECH_ACTIVITY`, `SILENCE_INTERVAL`, `PARTICIPATION_TREND`, `SENSOR_HEALTH`)
- `severity` (VARCHAR(32): `INFO`, `LOW`, `MEDIUM`, `HIGH`)
- `item_type` (VARCHAR(32): `OBSERVED_MEASUREMENT`, `STATISTICAL_ESTIMATE`, `PEDAGOGICAL_RECOMMENDATION`)
- `explanation` (TEXT)
- `suggested_action` (TEXT)
- `supporting_signals` (JSON: measured values with units and thresholds)
- `confidence_score` (FLOAT: 0.0 - 1.0)
- `confidence_limitations` (TEXT: boundary conditions and hardware caveats)
- `is_dismissed` / `dismissed_reason` (BOOLEAN / TEXT)
- `is_applied` / `applied_notes` (BOOLEAN / TEXT)
- `data_timestamp` / `created_at` (DATETIME)

## 4. API Specification

### 4.1 Get Reasoning Rules Catalog
```http
GET /api/recommendations/rules
```
**Response**: Returns complete transparent definitions of all rules, including trigger thresholds, primary signals, and rationale.

### 4.2 Generate Recommendations for a Session
```http
POST /api/recommendations/generate/{session_id}
```
**Query Parameters**:
- `force_regenerate`: boolean (default `false`)

**Response**:
```json
{
  "session_id": 1,
  "summary": {
    "verified_present_count": 6,
    "total_enrolled_count": 8,
    "attendance_rate": 0.75,
    "speech_ratio": 0.14,
    "dialogue_turn_count": 1,
    "audio_modality_active": true,
    "vision_modality_active": true
  },
  "recommendations": [
    {
      "id": 1,
      "rule_id": "RULE_LOW_PARTICIPATION_QA",
      "title": "Low Verbal Interaction Detected: Consider Adding a Structured Q&A Activity",
      "category": "PARTICIPATION_TREND",
      "severity": "MEDIUM",
      "item_type": "PEDAGOGICAL_RECOMMENDATION",
      "explanation": "Speech activity is estimated at 14.0% of session time with approximately 1 turn-taking events. This indicates a largely silent or passive classroom phase.",
      "suggested_action": "Pause the lecture and prompt students with an open-ended question using Think-Pair-Share or a digital polling poll.",
      "supporting_signals": {
        "speech_ratio": 0.14,
        "dialogue_turns": 1,
        "session_duration_minutes": 25.0
      },
      "confidence_score": 0.85,
      "confidence_limitations": "Audio VAD estimates speech intervals across the entire room. It does not measure cognitive attention or individual student comprehension.",
      "is_applied": false,
      "is_dismissed": false,
      "data_timestamp": "2026-10-28T15:30:00"
    }
  ],
  "epistemological_notice": "Attention, emotional valence, comprehension, and learning outcomes are internal cognitive/psychological states and are NEVER presented as directly measured facts."
}
```

### 4.3 Get Stored Recommendations for a Session
```http
GET /api/recommendations/session/{session_id}
```

### 4.4 Teacher Action: Apply Recommendation
```http
POST /api/recommendations/{recommendation_id}/apply
Content-Type: application/json

{
  "notes": "Introduced a 3-minute think-pair-share prompt."
}
```

### 4.5 Teacher Action: Dismiss Recommendation
```http
POST /api/recommendations/{recommendation_id}/dismiss
Content-Type: application/json

{
  "notes": "Deliberate silent individual writing exercise."
}
```

## 5. Frontend Dashboard Integration (`InsightsView.tsx`)

The dashboard exposes the reasoning agent with full transparency:
1. **Epistemological Banner**: Permanent reminder that cognitive states are not measured.
2. **Modality Sensor Status**: Visual badges indicating whether Audio and Vision data streams are currently operational or simulated.
3. **Multimodal Metric Overview**: Clean summary cards displaying verified roster attendance, cross-session baseline drop, speech vs. silence percentage, dialogue turnover, and spatial headcount discrepancy.
4. **Item Type Filter Tabs**: Allows instructors to isolate:
   - **All Items**
   - **Pedagogical Suggestions** (`PEDAGOGICAL_RECOMMENDATION`)
   - **Observed Sensor Facts** (`OBSERVED_MEASUREMENT`)
   - **Statistical Approximations** (`STATISTICAL_ESTIMATE`)
5. **Supporting Signal Badges**: Every card displays exact supporting signal values, units, and trigger conditions.
6. **Confidence & Limitations Callout**: Clearly documents boundary conditions (e.g. ambient acoustics, camera blind spots).
7. **Teacher Intervention Controls**: Interactive buttons to **Apply with Notes** or **Dismiss as Deliberate Pedagogy**.
8. **Public Rule Catalog Modal**: Transparent inspection of all codified engine rules.
